# Legacy Doctors identity

Source: user-supplied ID VISUAL - LEGACY DOCTORS archive.

The main nine-page identity manual specifies #0A3D91, #0A1F3C, black, white and a yellow/gold gradient. Its typography page specifies Rovan for the wordmark and Poppins as the supporting typeface. The separate branding_kit.pdf mentions Montserrat; this implementation follows the more detailed identity manual and its supplied Poppins font files.

Official horizontal gold/white logo: header and footer. Official white horizontal logo: original scrolling logo strip. All existing non-logo images, animation IDs and Webflow scripts remain intact. Colour filters on artwork containers adapt the orange template imagery without replacing the original files or animated elements.

Font license is included in fonts/OFL.txt. The Rovan wordmark is rendered from the supplied logo artwork; no unprovided font file is assumed.
